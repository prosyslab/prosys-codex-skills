# 논문 시스템 다이어그램 평가

사용자가 제공한 그림을 직접 보고 아래 다섯 기준의 충족 여부와 구체적인 수정안을 제시한다. 요청이 평가에 한정되면 원본 그림을 수정하지 않는다.

## 그림 확인

- 첨부 이미지 또는 사용자가 지정한 그림 파일을 시각적으로 확인한다. 로컬 이미지는 사용 가능한 이미지 보기 도구로 연다. PDF 등은 해당 그림을 렌더링해 확인한다. 파일명이나 텍스트 추출 결과만으로 판정하지 않는다.
- 개념을 나타내는 블록, 연결 화살표, 반복·피드백 경로를 식별한다. 그룹을 감싸는 외곽 프레임, 범례, 제목 영역은 개념 블록과 구분한다.
- 화살촉과 경로를 따라 실제로 앞 단계로 돌아오는 반복·피드백 연결인지 확인한다. 단지 선이 휘었거나 왼쪽을 향한다는 이유로 순환 예외로 간주하지 않는다. 순환 여부가 불분명하면 그 판단을 유보한다.
- 이미지가 없으면 평가할 그림을 요청한다. 해상도나 가림 때문에 확인할 수 없는 항목은 ‘판정 불가’로 표시한다.

## 평가 기준

| 항목 | 충족 조건 | 예외 및 해석 |
| --- | --- | --- |
| 화살표의 직교성 | 비순환 화살표의 모든 선분이 수평 또는 수직이다. 직각으로 꺾인 연결은 허용하고 대각선은 금지한다. | 순환 연결은 이 제약에서 제외한다. 화살촉 자체의 사선은 검사 대상이 아니다. |
| 화살표의 진행 방향 | 비순환 흐름은 왼쪽에서 오른쪽으로 진행하며, 수평 선분이 왼쪽으로 역행하지 않는다. | 위·아래 연결을 위한 수직 선분은 허용한다. 순환 연결의 복귀 경로는 역방향을 허용한다. |
| 개념 블록의 비율 | 각 개념 블록의 가로와 세로 길이가 같아 정사각형이다. | 블록끼리 크기가 모두 같아야 한다는 조건과 혼동하지 않는다. 사용자가 별도 해석을 지정하면 따른다. |
| 블록 간격 | 동일한 행·열 또는 같은 수준에서 비교 가능한 인접 블록의 가장자리 사이 빈 간격이 균일하다. | 중심 간 거리와 구분한다. 서로 다른 그룹이나 계층의 간격은 따로 비교하고, 그룹 간 여백 차이는 맥락을 설명한다. |
| 배치의 대칭 | 가능하면 상하·좌우의 위치, 정렬, 여백이 대칭을 이룬다. | 권장 기준이다. 흐름과 의미를 보존하면서 개선할 수 있는지 판단하며, 대칭을 위해 시스템 구조를 바꾸지 않는다. |

순환 예외는 화살표 두 항목에만 적용한다. 순환에 참여하는 블록도 비율·간격·대칭 평가에 포함한다. 반복 경로가 있는 그림 전체를 예외 처리하지 않는다.

래스터 이미지의 안티앨리어싱, 그림자, 선 두께 때문에 생기는 미세한 차이를 확정적인 위반으로 과장하지 않는다. 치수를 실제로 측정한 경우에만 수치를 제시하고 측정값인지 추정값인지 밝힌다. 임의의 픽셀 허용오차나 점수 배점을 공식 기준처럼 만들지 않는다.

## 평가 결과

사용자의 언어로 먼저 전체 충족 여부를 짧게 설명한다. 이어 다섯 항목을 표로 제시한다.

- 필수 네 항목: ‘충족 / 위반 / 판정 불가 / 해당 없음’과 관찰 근거.
- 대칭 항목: ‘양호 / 개선 권장 / 판정 불가’와 관찰 근거.
- ‘해당 없음’은 검사할 블록이나 비순환 연결 등이 실제로 없을 때만 사용한다.

위반 또는 개선 지점은 블록의 라벨과 상대 위치로 특정하고, 관찰한 문제와 실행 가능한 수정안을 연결한다. 예: ‘Encoder → Decoder 연결이 대각선이므로 수평–수직 직각 경로로 변경’. 라벨이 안 보이면 ‘왼쪽 위 블록’처럼 위치로 지칭한다.

필수 위반을 먼저, 권장 대칭 개선을 다음으로 정리한다. 수정안은 연결의 출발점·도착점과 시스템 의미를 유지한다. 판정 불가 항목이 있으면 전체가 모든 기준을 충족한다고 단정하지 않는다. 총점이나 별도 디자인 기준은 사용자가 요청하지 않는 한 추가하지 않는다.
